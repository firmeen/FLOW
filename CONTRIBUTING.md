# Contributing to FLOW

Use Issues to propose work, create a focused branch, and submit a pull request targeting `main`.

Phase/round implementation PRs must follow `docs/07-delivery/development-phases/README.md` and `docs/07-delivery/development-phases/FLOW_MERGE_POLICY.md`: required checks must complete successfully before merge, direct pushes to `main` are prohibited, and the next round cannot begin until the previous implementation PR has merged successfully.
