# Employees

Controls the complete employee documentary lifecycle from approved headcount through employment, payroll, access/equipment, changes, and exit.

## End-to-end lifecycle
```text
Headcount/budget approval → recruiting/selection → offer → employment agreement → job description → privacy/confidentiality/IP → payroll/statutory setup → device/access provisioning → policy acknowledgements → employment changes → recurring payroll → resignation/termination → final pay/property/handover → access revocation → personnel archive
```

## Control principles
- employment terms and compensation changes must have an effective written record;
- personal/HR files live in restricted storage, never in Git;
- access follows least privilege and is reviewed on join/move/leave events;
- payroll must reconcile to effective terms and bank/statutory filings;
- exit is not complete until system access, company property, payroll, customer/vendor ownership, and records are closed.

Final employment documents should be reviewed against current Thai labour requirements.
