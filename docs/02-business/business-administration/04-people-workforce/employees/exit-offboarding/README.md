# Employee Exit & Offboarding

Coordinates legal/HR, payroll, security, finance, property, customer/vendor ownership, and knowledge-transfer actions when employment ends.

## Workflow
```text
Resignation/termination initiated → legal/HR requirements → last day → final payroll/benefits/statutory actions → work/customer/vendor handover → company property inventory → privileged/general access revoked → shared secrets rotated where needed → bank/payment/admin authority removed → final documents → personnel archive
```

## Access review minimum
Company email, GitHub, cloud providers, Vercel/Supabase/GCP where used, domain/DNS, password manager, payment providers, banking/accounting, CRM/support, social accounts, drives, local SSH/API tokens, and company devices.

## Completion gate
The employee may be physically gone while offboarding is still incomplete. Close only when payroll, property, work ownership, customer/vendor responsibilities, access, authority, and retention tasks are verified.
