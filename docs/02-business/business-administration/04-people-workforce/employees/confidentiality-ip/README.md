# Employee Confidentiality & IP

Controls employee obligations for confidential information, source code, customer/vendor data, credentials, work product ownership, pre-existing IP, and return/deletion on exit.

## Required topics
Company confidential information, customer/vendor confidential information, credentials/source code, permitted use/disclosure, work-product/IP ownership, pre-existing IP disclosure, open-source/third-party code constraints, invention/work disclosure, device/data handling, return/deletion, and survival after employment.

## Workflow
```text
Role/data access assessed → applicable confidentiality/IP terms selected → legal/HR review → signature/acknowledgement → access provisioned → changes documented → exit reminder/return/deletion → archive
```

## Failure modes
Employee creates core work in a personal account with unclear ownership; pre-existing code is mixed into product without disclosure; customer data remains on personal storage; exit happens without IP/source handover.
