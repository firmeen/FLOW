# Employee Equipment & Access

Controls issue, custody, privilege, periodic review, transfer, and revocation of devices and business-system access.

## Onboarding chain
```text
Employment effective → manager confirms access profile → company identity/email → MFA → approved application/cloud/repository roles → device issue/custody acknowledgement → security setup → access register → validation
```

## Access record
User, role/business need, systems, permission level, privileged/admin flag, approver, start date, MFA/device status, owner/manager, review date, changes, and revocation date.

## Equipment record
Asset ID, device/serial, custodian, issue date, condition/accessories, encryption/security status, transfer/repair history, return date, and disposal/handover outcome.

## Control rule
Employment in engineering does not automatically justify access to production databases, billing, payroll, banking, domain registrar, payment providers, or every cloud system.
