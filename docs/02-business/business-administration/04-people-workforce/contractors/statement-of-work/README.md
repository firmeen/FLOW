# Contractor Statement of Work (SOW)

Defines the measurable work package that converts a contractor agreement into an executable engagement.

## Required fields
SOW ID, objective, deliverables, explicit out-of-scope items, dependencies, milestones, timeline, acceptance criteria, fees/payment milestones, change-request process, repository/environment, security/data constraints, documentation, testing/quality requirements, handover, and warranty/bug-fix period if agreed.

## Workflow
```text
Need → scope drafted → technical/business owner review → cost/timeline → security/data review → approval → contractor acceptance → milestone tracking → changes through documented change request → acceptance → payment milestone
```

## Failure modes
“Build the feature” with no acceptance criteria; contractor controls production credentials without defined need; undocumented scope growth; payment becomes due before deliverable/handover evidence.
