# Contractor IP Assignment

Ensures deliverables, code, designs, documents, and other work product used by FLOW have a clear company ownership path.

## Required schedule
Contractor/assignor, company/assignee, engagement/SOW, repositories/files/assets, creation period, deliverables, pre-existing IP exclusions, third-party/open-source components, effective transfer terms, signatures, and handover evidence.

## Chain
```text
Work created → creator/source identified → contractor/SOW ownership clause checked → assignment gap identified → assignment executed → source/design files delivered → third-party components disclosed → IP register updated
```

## Completion gate
A paid invoice is not evidence that all rights transferred. Final engagement closure requires ownership and source/file custody to reconcile.
