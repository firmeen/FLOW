# Contractor NDA

Controls confidentiality where material information is disclosed before or outside another agreement with adequate confidentiality terms.

## Record fields
Counterparty/legal person, purpose, information categories, mutual/one-way structure, effective date, term, survival period, permitted recipients, exclusions, return/destruction obligations, governing contract relationship, signed date, and secure storage link.

## Workflow
```text
Disclosure need → existing confidentiality terms checked → NDA need confirmed → approved template → deviations reviewed → authority/signature → NDA register → disclosure permitted within purpose → expiry/termination monitored
```

## Control rule
An NDA does not by itself transfer IP, authorize system access, permit personal-data processing, or approve a project. Those require their own contracts/controls.
