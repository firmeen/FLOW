# Contractor Agreements

Controls the umbrella legal/commercial relationship with contractors and freelancers.

## Required areas
Legal parties, independent relationship, scope mechanism/SOW, fees/payment process, confidentiality, IP ownership/assignment, security/data access, subcontracting if allowed, warranties/standards where agreed, compliance/tax responsibilities, termination, return/deletion, and handover.

## Workflow
```text
Contractor selected → identity/entity and commercial model checked → agreement prepared → legal/tax/security/privacy review according to risk → authority approval → signature → SOW activation → access onboarding → contract register
```

## Control rule
The agreement should define how specific work is commissioned through SOWs rather than embedding every future deliverable into one vague contract. Final contractor classification/terms should be validated with current professional advice.
