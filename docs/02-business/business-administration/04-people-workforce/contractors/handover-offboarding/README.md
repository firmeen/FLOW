# Contractor Handover & Offboarding

Closes the engagement by transferring source, documentation, knowledge, credentials, assets, and IP while removing all unnecessary access.

## Required closure checks
Source code pushed to company repository; branches/PRs documented; design/source files transferred; deployment/runbook/docs delivered; third-party components disclosed; defects/backlog listed; IP/assignment complete; credentials returned/revoked; customer/company data deleted from contractor-controlled systems where required; final invoice/retention issues resolved.

## Access review
Repositories, cloud/dev environments, production, databases, design tools, drives, password manager, APIs, VPN, customer accounts, messaging, and local SSH/API tokens.

## Workflow
```text
Final milestone → handover package → owner verification → acceptance → source/IP completeness → account/access revocation → secret rotation if needed → data deletion confirmation → final payment condition → archive
```

Final payment should not be used as the only signal that offboarding is complete.
