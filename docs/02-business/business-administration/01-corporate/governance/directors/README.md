# Directors

Maintains the controlled lifecycle of director appointment, authority, changes, resignation/removal, and related access implications.

## Required fields/evidence
Director identity reference in secure storage, appointment/effective date, approval/resolution, registered filing/status, signing authority, conflicts/related-party disclosures when relevant, resignation/removal evidence, and downstream access/provider changes.

## Join/change/leave workflow
```text
Decision → approval/resolution → filing where required → corporate register update → authority matrix update → bank/provider/customer/vendor KYC updates → privileged-access review
```

On exit, review bank signatory rights, payment-provider/admin rights, domain/cloud/GitHub/accounting systems, signing authority, and outstanding obligations. A former director must not remain operationally authorized because external systems were forgotten.
