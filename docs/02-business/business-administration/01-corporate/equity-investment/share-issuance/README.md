# Share Issuance

Controls creation/issuance of new shares and the resulting ownership, corporate, accounting, and filing evidence.

## Workflow
```text
Terms agreed → dilution/cap-table model → corporate/legal approvals → subscription/investment documents → conditions satisfied → funds received if applicable → shares issued → statutory registers/certificates updated → filings → cap table → accounting/tax records → investor evidence archive
```

## Required evidence
Approved terms, valuation/pricing basis where relevant, board/shareholder approvals, executed subscription/transaction document, funds receipt, issue date, shares/class/holder, statutory register/certificate, filing reference, final cap table, and accounting entry reference.

Do not mark an investment complete merely because funds arrived.
