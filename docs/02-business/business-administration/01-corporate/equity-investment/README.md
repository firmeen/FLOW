# Equity & Investment

Controls founder arrangements, capitalization, share issuances/transfers, shareholder agreements, and investment rounds.

## Core principle
Every cap-table change must trace to an approved and legally effective event. Do not update only a spreadsheet.

## End-to-end chain
```text
Terms/business decision → legal/corporate review → approvals → executed transaction documents → funds/consideration where applicable → share/register action → statutory filing where required → cap table update → accounting/tax treatment → investor evidence archive
```

## Review boundary
Share and investment documents can create material legal/tax consequences. Final execution should use current professional advice and actual company particulars.
