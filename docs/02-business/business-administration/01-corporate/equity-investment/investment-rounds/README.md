# Investment Rounds

Organizes the end-to-end evidence for financing discussions, diligence, approval, execution, funds, ownership changes, and post-closing obligations.

## Data-room structure
Corporate records, cap table, shareholder records, IP chain of title, material customer/vendor contracts, workforce/contractor agreements, financial statements/management accounts, tax filings, privacy/security documentation, disputes, bank/payment-provider information, and insurance if applicable.

## Workflow
```text
Round plan → term discussion → diligence → cap-table model → approvals → definitive documents → conditions precedent → funds → issuance/transfer → filings/registers → cap table/accounting → investor reporting calendar → closing archive
```

## Completion gate
Closing is not complete until executed documents, funds, ownership registers, filings, accounting, cap table, investor rights, and recurring reporting obligations reconcile.
