# Open-Source Licenses

Controls the component/licence evidence needed to understand third-party obligations in FLOW software and distributed assets.

## Component register fields
Package/component, version, source, licence, direct/transitive significance, modification status, use/distribution model, notice/attribution requirement, source-disclosure or copyleft consideration, review result, owner, and remediation/exception.

## Workflow
```text
Dependency proposed/identified → licence determined → intended use assessed → obligations reviewed → approve/replace/exception → notices/documentation updated → version monitored
```

## Triggers
New dependency, licence/version change, distribution model change, customer diligence, acquisition/investment diligence, or discovery of unknown code/assets.

The register supports review; unusual licensing questions should be escalated for appropriate legal advice.
