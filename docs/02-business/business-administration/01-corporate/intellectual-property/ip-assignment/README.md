# IP Assignment

Controls written transfer of intellectual-property rights to FLOW when ownership does not arise automatically or when explicit confirmation is prudent.

## Assignment schedule
Identify assignor, assignee, agreement/source relationship, asset/work description, repositories/files/domains/designs covered, creation period, pre-existing exclusions, consideration if relevant, effective date, signatures, and related confidentiality/handover obligations.

## Chain of title
```text
Work created → creator identified → existing employment/contractor/founder terms checked → gap identified → assignment signed → source/provenance evidence retained → IP register updated
```

## Failure modes
Generic assignment that does not identify the work; contractor paid but source stays in personal repo; brand designer ownership never transferred; pre-incorporation founder work has no documented path to the company.
