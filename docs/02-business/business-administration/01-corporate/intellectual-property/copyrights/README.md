# Copyright Evidence

Preserves provenance and ownership evidence for source code, designs, website content, documentation, illustrations, videos, marketing assets, and other copyright works.

## Evidence sources
Creator/author, creation date/history, repository or source-file history, employment/contractor/founder agreement, assignment/licence, third-party inputs, publication/release record, and version/hash where useful.

## Operating controls
- distinguish company-owned work from licensed or third-party work;
- record contributor relationship and ownership basis;
- retain original editable/source files for important assets;
- track commissioned work and assignment status;
- preserve notices/attribution required by licences.

Do not assume possession of a file equals ownership of the rights in it.
