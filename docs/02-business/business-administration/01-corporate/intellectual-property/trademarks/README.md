# Trademarks

Tracks trademark clearance, applications, registrations, classes/services, ownership, renewals, oppositions/actions, and licensed uses for FLOW brands.

## Register fields
Mark/word/logo, owner entity, jurisdiction, class/services, application/registration number, filing/registration date, status, adviser/authority, renewal date, opposition/office-action deadlines, evidence link, and permitted/licensed uses.

## Workflow
```text
Brand/market need → clearance/search → filing strategy → approval → application → authority correspondence → registration/status → use guidelines → renewal monitoring
```

## Control rule
The brand asset used publicly should be traceable to the registered/applied mark and owner. Material logo changes may require a fresh assessment rather than assuming the old registration covers the new form.
