# Signed Document Evidence

Defines the minimum evidence package for material agreements, resolutions, approvals, acknowledgements, or other signed records.

## Evidence package
Final signed document, all incorporated schedules/annexes, signature audit trail/certificate where available, template/version or document hash/reference, execution/effective date, signatory identity and authority evidence when material, related approvals, amendments/change orders, renewal/termination notices, and register entry.

## Workflow
```text
Document finalized → signatory/authority verified → signature process → completed copy received → completeness/integrity check → execution/effective date confirmed → register → obligations activated → secure archive
```

## Control rule
Never replace the original executed document when amended. Preserve original + amendment + any current consolidated working view. A regenerated PDF is not automatically the same evidence as the originally executed file.
