# Support Policy

Defines what customer support covers, how cases enter the system, expected response model, escalation, and boundaries between support, bug fixing, configuration, training, and paid custom work.

## Required fields
Support channels, hours/time zone, authorized contacts, severity definitions, target response/update expectations, business-hours/emergency handling, unsupported devices/versions where relevant, escalation route, customer information required, and case-closure rules.

## Case flow
```text
Request received → customer/account verified → severity/type classified → owner assigned → response → investigation/workaround → engineering/privacy/security escalation if needed → resolution/customer confirmation → root-cause or follow-up task → close
```

## Evidence
Case ID, timestamps, severity changes, communications, technical findings, commitments made, resolution, and related incident/problem records.
