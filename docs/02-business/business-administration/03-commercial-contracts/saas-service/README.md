# SaaS Service Commitments

Controls customer-facing service commitments that sit beside the core commercial contract: SLA, support, maintenance, pilot/beta, cancellation/refund policy, and service incidents.

## Principle
Every promise must map to an operating capability and evidence source. FLOW should not publish response, uptime, backup, deletion, or support commitments that cannot be measured and consistently performed.

## Workflow
```text
Service promise proposed → operational capability measured → engineering/support/privacy/security/finance impact → approval → controlled policy/version → customer-contract linkage → monitoring/evidence → exceptions/incidents → periodic review
```

## Evidence rule
If a commitment is measurable, define the measurement source, period, exclusions, owner, escalation, and retained evidence needed to prove compliance or calculate a remedy.
