# Pilot & Beta

Controls limited testing of evolving FLOW capabilities before ordinary production commitments apply.

## Required terms
Pilot objective, customer/branch/site, duration, included workflows/features, experimental/excluded functions, permitted data, production-risk limitations, manual fallback, support channel, pricing/free status, feedback rights, confidentiality/IP treatment, success criteria, conversion path, and early-exit conditions.

## Workflow
```text
Pilot candidate → scope/risk/data review → written pilot terms → setup with isolated/limited permissions → start baseline → feedback/incident tracking → success review → convert / extend / stop → data/access cleanup → evidence archive
```

## Completion gate
A pilot does not silently become permanent production. Conversion requires an explicit production contract/order and confirmation that operational/privacy/security requirements are ready.
