# Maintenance Policy

Controls routine and emergency maintenance commitments and how planned technical work affects customer communication and SLA treatment.

## Required definition
Maintenance types, standard windows, advance-notice target, emergency-change exception, customer impact classification, notification channels, SLA exclusion rule if applicable, rollback/escalation conditions, and post-maintenance verification.

## Workflow
```text
Maintenance need → impact/risk assessment → schedule → approval/change control → customer notice if required → pre-check/backup/rollback readiness → execution → service verification → incident escalation if failed → completion notice/evidence
```

## Control rule
A maintenance exclusion in an SLA should match the actual notice and change process. Do not classify unplanned outages as planned maintenance after the fact.
