# Integration Partner Agreements

Controls external systems exchanging data or events with FLOW through APIs, webhooks, files, or embedded workflows.

## Required terms/controls
Integration purpose, data fields, controller/processor roles where relevant, API credential ownership, scopes, rate/usage limits, security requirements, version/change process, availability dependencies, webhook/retry behavior, incident contacts, branding, support ownership, customer consent/authorization, and termination/revocation.

## Lifecycle
```text
Use case → technical/data mapping → security/privacy review → agreement → test credentials → acceptance → production activation → monitoring/change management → incident handling → deprecation/termination → credential revocation/data cleanup
```

## Evidence
Integration ID, customer/partner scope, enabled environments, credentials reference, mapping version, test evidence, production approval, and shutdown confirmation.
