# Implementation Partner Agreements

Controls third parties that configure, migrate, train, or deploy FLOW for customers.

## Responsibility map
Discovery, data collection/migration, configuration, branch setup, user creation, training, acceptance, support handoff, custom integrations, customer communications, and post-go-live warranty/support.

## Security/privacy controls
Named users, least privilege, customer authorization, permitted data, secure transfer, credential handling, audit/logging, subprocessor status where applicable, incident escalation, and deletion/offboarding.

## Workflow
```text
Partner/customer scope → SOW/responsibility matrix → access/data review → onboarding → implementation milestones → acceptance evidence → support handoff → final data/credential cleanup → settlement/archive
```

Partner access must not persist after the implementation need ends.
