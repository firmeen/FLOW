# Customer Change Orders

Controls customer changes that materially alter contractual scope, recurring fees, deliverables, implementation, data/security obligations, or other key terms.

## Change assessment
Record requested change, business reason, commercial impact, technical/implementation effort, data/privacy/security impact, billing/tax impact, target date, dependencies, and required approvals.

## Workflow
```text
Request → scope clarified → impact assessment → pricing/timing → specialist reviews → approval → customer acceptance/signature → contract register update → entitlement/configuration update → billing update → implementation → delivery/acceptance → archive with original agreement
```

## Completion gate
A signed change is not complete while billing or system entitlements still reflect the old scope. Conversely, operations must not implement a material scope change before required customer acceptance and approval.
