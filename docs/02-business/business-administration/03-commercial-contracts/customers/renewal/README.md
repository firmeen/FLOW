# Customer Renewal

Controls proactive renewal before contractual notice deadlines and ensures commercial, operational, billing, and contract records stay aligned.

## Renewal pack
Current MSA/Terms and Order Form, renewal/notice clause, current package/usage, recurring value, outstanding invoices, open disputes/support issues, planned price change, new scope proposal, DPA/SLA changes, customer contacts, and prior concessions.

## States
```text
UPCOMING → PREPARING → CONTACTED → NEGOTIATING → RENEWED
                                         └→ NON-RENEWAL / TERMINATION IN PROCESS
```

## Workflow
```text
Renewal window opens → account/finance/service review → pricing/scope decision → notice/proposal → negotiation → amendment/new order/no-change confirmation → signature/evidence → register/billing/entitlement update → next renewal scheduled
```

Missing a notice deadline because the date was not calendared is a governance failure, not only a sales issue.
