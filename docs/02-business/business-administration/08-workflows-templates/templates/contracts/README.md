# Contract Templates

Holds controlled baselines for customer, vendor, partner, NDA, contractor, and other commercial agreements.

## Template metadata
Template ID, agreement type, owner, version, effective date, intended use/customer/vendor segment, governing related documents, standard commercial variables, mandatory clauses, approved fallbacks, legal-review triggers, prohibited changes, approver/signatory class, and superseded version.

## Use workflow
```text
Business need → correct approved template → fill commercial/party variables → identify deviations → finance/privacy/security/product review as impacted → legal review threshold → approval → execution → contract register/obligation activation
```

## Control rule
Do not create one-off contracts by copying an old signed customer/vendor agreement. Start from the current approved template and preserve every deviation explicitly.
