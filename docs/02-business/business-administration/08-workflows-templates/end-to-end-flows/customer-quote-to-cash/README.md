# Customer Quote-to-Cash — End-to-End Flow

Connects customer commercial agreement to delivery activation, billing, collection, payment evidence, accounting/tax treatment, and renewal.

## Flow
```text
Lead/customer qualified
→ legal/billing identity verified
→ quotation/proposal approved and issued
→ MSA/Terms + Order Form selected/prepared
→ DPA/SLA/security schedules assessed if needed
→ signature/acceptance evidence
→ contract register/obligations
→ workspace/onboarding/go-live prerequisites
→ billing trigger
→ invoice + AR
→ payment/provider confirmation
→ WHT difference/certificate if applicable
→ receipt/tax document
→ bank/provider reconciliation
→ accounting/tax records
→ renewal/notice calendar
```

## Exception branches
Quotation revision, procurement PO requirement, non-standard clause, delayed implementation, disputed invoice, partial/overpayment, failed/pending payment, settlement mismatch, missing WHT certificate, credit/refund, scope change, early termination, or customer-data deletion request.

## Completion gate
A paid invoice is not the end. Quote-to-cash closes only when contract/entitlement, invoice/AR, payment/settlement, tax/accounting, customer evidence, and renewal obligations reconcile.
