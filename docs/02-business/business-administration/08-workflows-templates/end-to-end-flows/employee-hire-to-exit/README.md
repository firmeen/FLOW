# Employee Hire-to-Exit — End-to-End Flow

Coordinates employment, payroll, equipment, access, policy, confidentiality/IP, changes, and offboarding.

## Flow
```text
Headcount/budget approved
→ candidate selected
→ offer/employment agreement
→ job description
→ privacy/confidentiality/IP
→ payroll/statutory onboarding
→ company identity/device/access + MFA
→ policy acknowledgements
→ employment/compensation/role changes documented
→ recurring payroll/reconciliation
→ resignation/termination
→ final payroll/statutory actions
→ property/work/customer/vendor handover
→ all access/authority revoked
→ secret rotation where needed
→ personnel record archive
```

## Required owners
Hiring manager/business owner, HR/management, payroll/finance, IT/security/access owner, employee, and legal/accounting advisers where required.

## Completion gate
A last working day is not completion. Final pay, property, source/work ownership, customer/vendor responsibility, privileged/general access, bank/payment authority if any, and retention tasks must be verified.
