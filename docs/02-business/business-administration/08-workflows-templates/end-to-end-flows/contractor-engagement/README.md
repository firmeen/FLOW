# Contractor Engagement — End-to-End Flow

Controls contractor work from approved need through SOW, access, delivery, acceptance, payment, IP/source handover, and offboarding.

## Flow
```text
Need/scope approved
→ contractor selected
→ contractor agreement + SOW
→ NDA/IP/security/privacy requirements
→ least-privilege access
→ milestone work/delivery
→ objective acceptance evidence
→ invoice
→ WHT/tax/payment approval
→ bank payment/accounting
→ final source/design/docs/credential handover
→ IP/component completeness
→ access revocation + data deletion confirmation
→ final settlement
→ engagement archive
```

## Exception branches
Scope change, delayed milestone, conditional acceptance, security incident, contractor substitution, third-party/open-source component issue, IP gap, disputed invoice, or missing handover.

## Completion gate
Do not close because the contractor invoiced or stopped working. Company custody of deliverables, documentation, IP rights, credentials, and access revocation must all reconcile.
