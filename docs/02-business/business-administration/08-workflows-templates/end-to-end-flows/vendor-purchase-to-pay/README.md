# Vendor Purchase-to-Pay — End-to-End Flow

Connects business need and budget authority to vendor diligence, contracting, receiving, invoice validation, payment, tax, accounting, reconciliation, and renewal.

## Flow
```text
Need identified
→ budget/authority
→ vendor selection/quote
→ legal/security/privacy review as needed
→ contract/PO
→ service/product delivered
→ receiving/acceptance evidence
→ vendor invoice
→ invoice/PO/duplicate/master-data checks
→ tax/WHT review
→ AP/payment voucher/approval
→ bank payment
→ WHT certificate/filing if applicable
→ accounting
→ bank reconciliation
→ vendor renewal/cancellation monitoring
```

## Controls
No material payment based solely on chat approval. Verify vendor bank changes independently. Link invoice to contract/PO and acceptance. Track auto-renewal/cancellation dates. For data-processing vendors, close subprocessor/data obligations on termination.

## Completion gate
Purchase-to-pay ends when the obligation, payment, tax certificate/filing, ledger, bank reconciliation, and vendor renewal/closure status all agree.
