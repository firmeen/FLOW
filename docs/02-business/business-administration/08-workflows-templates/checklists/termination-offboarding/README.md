# Termination & Offboarding Checklist

Reusable closure gate for relationships where contracts, access, money, data, property, credentials, and retained evidence must all be resolved.

## Checklist
- [ ] Trigger, authority, effective date, and contractual/HR basis verified.
- [ ] Future billing/renewal/recurring payment stopped as applicable.
- [ ] Final invoice/refund/credit/payroll/vendor balance calculated and approved.
- [ ] Payment/settlement/accounting/tax consequences reconciled.
- [ ] Company/customer/vendor property and work-product handover complete.
- [ ] Data export/return obligations completed.
- [ ] User/admin/API/integration access revoked.
- [ ] Shared secrets/tokens rotated where exposure existed.
- [ ] Bank/payment/signatory authority removed when applicable.
- [ ] Customer/vendor/employee/contractor responsibilities reassigned.
- [ ] Privacy retention/deletion and subprocessor/backup actions scheduled/completed.
- [ ] Required legal/accounting/security evidence separated for retention.
- [ ] Registers, asset/access lists, and compliance calendar updated.
- [ ] Final communication/confirmation sent where appropriate.
- [ ] Secure archive link and retention class verified.

An ended relationship is not administratively closed until every applicable item is complete or recorded as an approved exception.
