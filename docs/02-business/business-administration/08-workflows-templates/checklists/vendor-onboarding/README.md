# Vendor Onboarding Checklist

Verifies that FLOW understands the supplier, commercial commitment, data/security exposure, payment/tax setup, ownership, and exit path before use.

## Checklist
- [ ] Business need and internal owner confirmed.
- [ ] Vendor legal identity and pricing/quotation collected.
- [ ] Budget/approval authority satisfied.
- [ ] Contract/terms and auto-renewal/cancellation window reviewed.
- [ ] Data processed and system/access scope documented.
- [ ] Security review completed according to risk.
- [ ] Privacy/DPA/subprocessor/transfer obligations completed if applicable.
- [ ] Payment/bank details independently verified.
- [ ] Tax/WHT/vendor-master setup reviewed.
- [ ] Support/incident/escalation contacts recorded.
- [ ] Account ownership uses company-controlled identity where practical.
- [ ] API/credentials stored securely with owner.
- [ ] Data export/deletion/termination plan understood.
- [ ] Renewal/cancellation dates calendared.
- [ ] Vendor register entry created.

Production/confidential-data use before required review completion is an exception requiring explicit approval.
