# Incorporation Checklist

Objective completion gates for establishing the company and activating its administrative controls.

## Checklist scope
- [ ] Entity/name/capital/shareholder/director/objective decisions documented.
- [ ] Registered-address evidence ready.
- [ ] Required incorporation documents reviewed and signed.
- [ ] Official submission and registration result verified.
- [ ] Current corporate master/registers created.
- [ ] Shareholder records and cap table reconcile.
- [ ] Signing/approval authority matrix activated.
- [ ] Tax/accounting setup owner and status recorded.
- [ ] Corporate bank/KYC setup completed or tracked as named exception.
- [ ] Founder IP/domain/cloud/brand assets have documented company ownership/control path.
- [ ] Payment-provider and major vendor/customer KYC particulars updated.
- [ ] Invoice/contract/privacy legal-entity particulars use current data.
- [ ] Compliance/renewal calendar seeded.
- [ ] Executed sensitive evidence stored outside Git with secure references.

## Completion
All incomplete items must have owner, reason, target date, risk, and interim control.
