# Customer Onboarding Checklist

Verifies that commercial, contract, billing, entitlement, privacy/security, and operational setup match before production use.

## Checklist
- [ ] Customer legal/billing identity verified.
- [ ] Accepted quotation/proposal identified.
- [ ] Governing MSA/Terms version confirmed.
- [ ] Order Form signed/accepted and registered.
- [ ] Non-standard obligations assigned to owners.
- [ ] DPA/SLA/security schedules completed where needed.
- [ ] Billing frequency/start/date/payment terms match signed order.
- [ ] Product/package/branch/module entitlement matches signed order.
- [ ] Implementation/migration dependencies and acceptance criteria agreed.
- [ ] Customer admin/contacts and support route recorded.
- [ ] Payment method/provider configuration validated when used.
- [ ] Privacy/data processing role and subprocessor implications reviewed.
- [ ] Go-live prerequisites tested.
- [ ] Renewal/notice dates calendared.
- [ ] Contract and onboarding evidence stored/linked securely.

## Gate
Do not hide mismatches as “we will fix later”; record formal exceptions with owner and customer/commercial impact.
