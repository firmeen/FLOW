# Contractor Onboarding Checklist

Verifies that scope, legal relationship, IP, security/data access, payment/tax, and handover obligations are defined before work begins.

## Checklist
- [ ] Business need/scope/budget approved.
- [ ] Contractor identity/entity and payment details captured securely.
- [ ] Contractor agreement executed.
- [ ] SOW has deliverables, exclusions, milestones, acceptance criteria, fees, timeline, and handover.
- [ ] NDA/confidentiality coverage confirmed.
- [ ] IP ownership/assignment and pre-existing IP disclosures addressed.
- [ ] Security/privacy/data restrictions assessed.
- [ ] Least-privilege accounts created with owner/end date.
- [ ] Repository/environment scope limited to need.
- [ ] Third-party/open-source disclosure expectations agreed.
- [ ] Invoice/WHT/payment process communicated.
- [ ] Deliverable-acceptance owner assigned.
- [ ] Offboarding/source/docs/credential handover gate defined.

No production/customer data access by default; grant only when justified and approved.
