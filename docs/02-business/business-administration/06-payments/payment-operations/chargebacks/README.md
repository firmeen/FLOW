# Chargebacks & Payment Disputes

Controls provider dispute deadlines, evidence packages, responses, outcomes, fees/losses, accounting, and fraud/process follow-up.

## Dispute pack
Provider notice/reason code, amount/currency, response deadline, customer/order/payment references, accepted terms, proof of service/delivery where relevant, customer communications, refund history, fraud/risk evidence, response submitted, provider receipt, decision, fee/loss, and corrective action.

## Workflow
```text
Notice → deadline/register → evidence preserved/collected → eligibility/strategy → response drafted → legal/operations/finance review as needed → provider submission → outcome → settlement/accounting treatment → fraud/root-cause review → archive
```

Missing a response deadline is a control failure even if the underlying transaction was legitimate.
