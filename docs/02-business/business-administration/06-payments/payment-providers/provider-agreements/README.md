# Payment Provider Agreements

Controls the contractual terms governing payment processing and maps provider rights/obligations to FLOW's actual payment architecture.

## Review topics
Merchant/platform role, allowed use, settlement ownership, fees/overages, reserves/holds, payout timing, refund/void rules, disputes/chargebacks, fraud/risk controls, prohibited businesses/use cases, data/security/PCI responsibilities, API/webhook terms, service availability/support, unilateral changes, suspension/termination, data export, and liability.

## Workflow
```text
Provider selected → current terms/agreement obtained → money/data flow mapped → finance/security/privacy/legal review → deviations/risks → approval → signature/acceptance → contract register → operational controls/fees/reconciliation configured → renewal/change monitoring
```

## Completion gate
A provider cannot be considered production-ready until contract terms, actual settlement account, credentials ownership, refund authority, reconciliation reports, and incident contacts are all known.
