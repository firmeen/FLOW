# Tax Audit & Inquiry Support

Organizes evidence for authority inquiries, reviews, audits, corrections, and adviser responses without reconstructing years of activity.

## Case workflow
```text
Request received → deadline/register entry → scope clarified → evidence preserved → accountant/tax/legal adviser engaged as needed → source records/reconciliations compiled → response reviewed/approved → submission proof → follow-up questions → adjustment/payment/appeal if any → final outcome → lessons/control updates → archive
```

## Case file
Authority/request reference, dates/deadlines, issue scope, periods/taxes, assigned owner, advisers, documents supplied, internal analysis, approved responses, submission/receipt evidence, adjustments, payments/refunds, appeals, final closure, and legal-hold status.

Do not alter original accounting/tax records to make an inquiry easier; corrections require traceable adjustment.
