# Quotations

Controls formal commercial offers before contracting or order confirmation.

## Required fields
Quotation ID/version, issue/valid-until dates, customer legal/billing identity, product/package/scope, quantity/branch/user/device assumptions, subscription/service period, one-time/recurring fees, discounts, taxes, payment terms, assumptions/exclusions, contract reference, preparer, and approver.

## Workflow
```text
Scope/pricing understood → approved pricing/discount checked → operational feasibility checked → quotation prepared → review → issued → customer response → revision as new version if needed → accepted/rejected/expired/superseded status → link to contract/order
```

An accepted quotation must never be silently edited. Record a revision and preserve the accepted version.
