# Debit Notes

Controls supported increases or corrections to an existing billing/tax position where a debit-note mechanism is appropriate.

## Required evidence
Original invoice/document, reason for additional charge/correction, contractual basis, calculation, tax treatment, approval, debit-note number/date, customer communication, AR/accounting effect, and settlement status.

## Workflow
```text
Additional amount identified → contractual/tax basis checked → original matched → calculation reviewed → approval → debit note issued → AR/accounting/tax records updated → collection/reconciliation
```

Use a new normal invoice instead where that is the approved accounting/tax process; do not invent document types without accountant validation.
