# Billing Documents

Controls quotations, invoices, receipts, tax invoices, credit/debit notes, and numbering so commercial offers and financial documents remain unique, accurate, linked, and auditable.

## General rules
- use controlled unique identifiers;
- preserve issued/accepted versions;
- seller/customer legal particulars come from approved master data;
- link every billing document to the commercial event/contract/order;
- tax wording/templates must match actual registration status;
- corrections use revision, credit/debit, void, or replacement workflow rather than silent editing;
- issued numbers are never recycled.

## Workflow
```text
Commercial trigger → document prepared → pricing/tax/master-data validation → approval → issue → delivery/acceptance evidence → status/register update → payment/accounting/tax linkage → amendment/void handling if needed → archive
```
