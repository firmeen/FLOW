# Accounting

Defines how economic events become supported ledger entries, balances, reconciliations, and period-close evidence.

## Evidence principle
Every material journal or balance should be explainable through source evidence such as contract/order, invoice, receipt, payment, acceptance, tax document, payroll record, fixed-asset record, or approved adjustment.

## Operating chain
```text
Business event → source packet → accounting classification → entry → subledger/control-account update → reconciliation → period review → adjustment if required → close → retained support
```

## Controls
Approved chart of accounts, consistent period cut-off, AR/AP support, bank/provider reconciliation, controlled journals, reviewer sign-off, and separate evidence for adjustments and estimates.

Exact Thai accounting treatment belongs with the appointed accountant and actual transaction facts.
