# Chart of Accounts

Controls the account taxonomy used to classify FLOW's real economic events consistently.

## Design inputs
Revenue models, subscriptions/onboarding/services, payment-processing fees, cloud/software costs, payroll/contractor costs, marketing, professional fees, fixed assets, tax control accounts, AR/AP, prepayments/accruals, founder/shareholder advances, and other material transaction types.

## Change control
```text
New transaction need → existing account reviewed → accounting/tax impact assessed → accountant approval → account/code created or mapping changed → systems/templates updated → effective period recorded → reporting impact validated
```

## Register fields
Account code/name, type, purpose, allowed transaction examples, prohibited/misuse examples, tax mapping, reporting group, effective date, status, and replacement account if retired.

Do not create ad-hoc accounts to hide unreconciled transactions.
