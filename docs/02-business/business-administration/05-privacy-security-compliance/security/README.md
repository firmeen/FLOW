# Security Governance

Controls the policies and evidence showing how FLOW protects systems, data, identities, availability, and third-party dependencies.

## Scope
Information-security governance, access control, backup/recovery, incident response, vulnerability management, logging/monitoring, and vendor security.

## Operating principle
A policy creates an obligation. Do not state that FLOW performs quarterly reviews, annual tests, specific RPO/RTO, encryption, or monitoring unless the control is actually implemented and evidence can be produced.

## Control lifecycle
```text
Risk/requirement → policy/control design → owner/approver → implementation → evidence collection → periodic test/review → finding → remediation/exception → re-test → policy/control update
```

## Evidence rule
Every material control should have owner, frequency/trigger, systems in scope, execution evidence, reviewer, exceptions, remediation target, and next review.
