# Vendor Security

Controls risk review before and during use of third parties that access systems or process confidential/personal data.

## Intake dimensions
Service criticality, data/access scope, authentication/MFA, encryption, hosting/data location, incident terms, vulnerability practices, backup/continuity, subcontractors, certifications/evidence where relevant, deletion/export, privileged access, support escalation, and contractual security obligations.

## Workflow
```text
Vendor proposed → inherent risk/data classification → evidence/questionnaire/terms review → gaps → remediation/contract condition/exception → approval → production onboarding → periodic/change review → incident monitoring → offboarding/deletion
```

## Evidence
Assessment date, reviewer, scope, source documents, findings, risk rating, required actions, accepted residual risk and approver, next review, and termination evidence.
