# Security Incident Response

Controls detection, triage, containment, investigation, evidence preservation, communications, restoration, and corrective action for security incidents.

## Severity and ownership
Define incident commander/owner, severity levels, on-call/escalation contacts, technical leads, privacy/legal/business communication roles, and executive escalation criteria.

## Workflow
```text
Alert/report → triage/severity → contain → preserve evidence → investigate scope/cause → privacy/customer/regulatory obligations → eradicate/remediate → restore → monitor → communications → postmortem → corrective actions → closure
```

## Case evidence
Timeline, systems/accounts/data affected, actions/commands where appropriate, preserved logs, decisions, notifications, root cause, remediation, residual risk, lessons, and follow-up owners.

Do not destroy evidence through cleanup before preservation requirements are considered.
