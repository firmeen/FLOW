# Information Security Policy

Defines the umbrella security governance model for FLOW.

## Required domains
Roles and accountability, risk management, asset/data classification, identity/access, device/security configuration, software/change practices, vulnerability management, logging/monitoring, backup/recovery, incidents, vendors, privacy coordination, business continuity, training/acknowledgement, exceptions, and review cycle.

## Policy metadata
Owner, approver, version, effective date, scope, referenced standards/requirements if any, control owners, exception process, review trigger/date, evidence sources, and superseded version.

## Validation
Each policy statement must map to an implementable control. If current practice differs, either remediate the control or revise the policy honestly; do not keep aspirational promises presented as current fact.
