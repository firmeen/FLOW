# Data Breach & Privacy Incident

Connects technical incident response to privacy-role analysis, customer/DPA obligations, regulatory assessment, communication, remediation, and retained decision evidence.

## Workflow
```text
Detection → incident record → containment → preserve evidence → determine affected data/subjects/systems → controller/processor role → customer/DPA notice obligations → regulatory assessment → communications approval → notification where required → remediation/restoration → post-incident review → corrective actions → archive/legal hold as needed
```

## Required record
Incident ID, detection time/source, severity, affected systems/data categories, approximate scope, containment, timeline, role analysis, contractual deadlines, regulator/customer decision and rationale, communications, technical cause, remediation, lessons, and owners.

Maintain decision evidence even when the conclusion is that external notification is not required.
