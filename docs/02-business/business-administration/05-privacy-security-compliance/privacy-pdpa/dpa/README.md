# Data Processing Agreements (DPA)

Controls processor/controller contractual obligations and maps them to FLOW's actual technical and operational capability.

## Core subjects
Processing subject/duration, nature/purpose, data categories/subjects, documented instructions, confidentiality, security measures, subprocessors, rights assistance, privacy/security incident assistance, deletion/return, audit/information rights, and cross-border requirements where relevant.

## Pre-signing capability check
Confirm FLOW can meet requested incident-notification timing, deletion deadline, backup language, subprocessor notice/approval model, audit rights, data-location commitments, access/encryption controls, and rights-request assistance.

## Workflow
```text
Customer/vendor processing relationship → role analysis → standard DPA selected → deviations logged → privacy/security/engineering/legal review → approval → signature → DPA register → subprocessor/retention/incident obligations activated → renewal/termination handling
```

Do not accept customer-specific language that contradicts the architecture without an approved remediation commitment.
