# Subprocessors

Controls third parties that process personal data in support of FLOW services and the contractual/customer obligations created by using them.

## Register fields
Provider, service, purpose, data processed, customer/product scope, locations/countries, contract/DPA, security review, transfer considerations, onboarding date, customer notice/approval requirement, change date, owner, termination date, and deletion/export evidence.

## Onboarding workflow
```text
Vendor need → processing/data map → controller/processor role → DPA/terms → security review → transfer/data-location assessment → approval → subprocessor register → customer notice/contract obligations → production activation
```

## Offboarding
Stop new data, export required data, revoke credentials/integration, obtain deletion confirmation where appropriate, update register/list, satisfy customer notification obligations, and preserve contract/termination evidence.
