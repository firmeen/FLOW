# Privacy Notices

Controls audience-specific notices explaining how FLOW processes personal data for its own purposes.

## Possible audiences
Business customers/account users, website visitors/leads, applicants/employees, and end consumers where FLOW independently determines a processing purpose.

## Required notice controls
Audience/scope, controller identity/contact, purposes, data categories/sources, recipients/processors, international-transfer information where applicable, retention approach, rights/contact route, lawful basis/consent linkage where appropriate, effective date, version, and change history.

## Workflow
```text
Processing activity mapped → audience/role confirmed → notice drafted → legal/privacy + system-owner review → approval → publish → evidence of effective version → material-change rollout/notice → supersede/archive old version
```

## Validation gate
Every material statement should be traceable to a real data flow, system, vendor, retention rule, or operational practice. A notice that contradicts actual architecture is a control defect.
