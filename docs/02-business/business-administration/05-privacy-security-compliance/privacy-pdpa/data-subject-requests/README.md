# Data Subject Requests

Controls intake, identity verification, scope, system search, legal/role analysis, action, response, and completion evidence for privacy-rights requests.

## Case workflow
```text
Request received → case logged → identity verified proportionately → request type/scope → controller/processor responsibility → relevant systems/vendors identified → data/search completed → exceptions/legal review → action executed → response approved/sent → downstream completion verified → case closed
```

## Case record
Case ID, requester/contact in secure system, request type, received/due dates, identity-verification method, systems searched, customer/controller coordination if processor, decisions/exceptions, actions, response evidence, completion date, and legal-hold considerations.

## Control rule
Do not expose unnecessary personal data in the request register itself. The register should track the case while sensitive evidence stays restricted.
