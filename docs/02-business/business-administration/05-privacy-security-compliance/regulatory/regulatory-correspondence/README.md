# Regulatory Correspondence

Controls incoming/outgoing communications with regulators, tax/corporate authorities, banks' compliance teams, or other official bodies when a formal response or evidence package is required.

## Case record
Authority, request/reference, received date, response deadline, assigned owner, scope/questions, legal/accounting/privacy/security advisers, documents requested/supplied, response drafts, approval, submission method/date, receipt/reference, follow-up questions, outcome, and legal-hold/retention status.

## Workflow
```text
Request received → deadline logged → authenticity/scope verified → evidence preserved → advisers/owners assigned → response/evidence compiled → privilege/confidentiality review → approval → submission → receipt → follow-up → final outcome/control changes → archive
```

Do not send broad internal records without reviewing scope, confidentiality, personal data, and relevance.
