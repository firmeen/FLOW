# Corporate Compliance

Controls recurring entity-level obligations and evidence that corporate records remain current.

## Typical areas
Company/branch particulars, director/shareholder/capital changes, annual/statutory filings, financial-statement approvals/filings as applicable, licences/registrations, registered-address obligations, books/registers, and KYC refreshes for banks/providers/customers.

## Workflow
```text
Obligation/change → calendar/trigger → current corporate records → professional/corporate review → approval/signatures → filing/submission → authority result → register/master data → downstream KYC/template updates → next date
```

## Completion gate
A filed change is incomplete if the corporate master, bank/payment-provider KYC, invoicing/legal templates, or authority matrix still show the former state.
