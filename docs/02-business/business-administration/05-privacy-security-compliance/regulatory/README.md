# Regulatory & Compliance Matters

Controls documented assessment and correspondence for electronic transactions, payment-related compliance, corporate recurring obligations, and interactions with authorities/regulators.

## Principle
This folder does not declare that FLOW is regulated in a particular way. It records the actual question, facts, professional/regulatory interpretation, decisions, deadlines, filings/correspondence, and resulting controls.

## Workflow
```text
New activity/requirement/request → scope/facts → responsible owner → professional/legal/accounting/privacy review as needed → decision/obligation → implementation/filing/response → evidence → calendar/review
```

Material regulatory conclusions should cite the current adviser/authority basis in the secure record rather than being inferred from old internal notes.
